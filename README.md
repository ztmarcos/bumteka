# BUMTEKA

A modern web application portfolio built with React + Vite, featuring a terminal-inspired design.

## Prerequisites

- Node.js (v14 or higher)
- npm (comes with Node.js)

## Installation

1. Clone the repository:
```bash
git clone https://github.com/ztmarcos/bumteka.git
cd bumteka
```

2. Install dependencies:
```bash
npm install
```

## Development

To run the development server:
```bash
npm run dev
```
The app will be available at http://localhost:5173

## Building for Production

To create a production build:
```bash
npm run build
```

To preview the production build locally:
```bash
npm run preview
```

## Branches

- `main`: Production branch
- `bumtekaV1.1`: Development branch with latest features

## Project Structure

- `src/`: Source files
  - `App.jsx`: Main application component
  - `App.css`: Styles
- `public/`: Static assets
- `dist/`: Production build output

## Features

- Terminal-inspired design
- Responsive layout
- Project showcase
- Contact information
